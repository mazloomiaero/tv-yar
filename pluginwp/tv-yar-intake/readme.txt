فرم ثبت درخواست خدمت با شرت‌کد [tv_yar_intake] و اتصال یک‌طرفه به سامانه مدیریت خدمات فنی.

== Installation ==
1. پوشه `tv-yar-intake` را در `wp-content/plugins` کپی کنید.
2. پلاگین را فعال کنید.
3. از Settings → فرم TV Yar آدرس API و کلید را وارد کنید.
4. شرت‌کد `[tv_yar_intake]` را در صفحه دلخواه بگذارید.

== Shortcode ==
[tv_yar_intake]
